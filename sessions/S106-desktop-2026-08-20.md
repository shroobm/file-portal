## §8 Where I Was Wrong, Caught By Re-Measurement

**The first build of the triage shipped a different rule from the one I had measured.** My
adjudication used an ILLUSTRATION-frame precedence (a page that merely *cites* a figure inside
a worked example is not promoted); the shipped code asked only "does the text name a FIGURE".
On the repaired map that promoted **16 of 49**, not 8 — including p682 and p1111, which I had
already looked at and adjudicated as figure-less frames. **The 83 % I reported to Rab was
measured on a rule the code did not implement.**

This is `docs/45` §1 Family 1 exactly — *the sentence describes the neighbour of the probe* —
committed by the session that documented it, one day later. It was caught only because I ran
the shipped code against the ad-hoc classifier instead of assuming they agreed. The precedence
is now in the code, the shipped set reproduces the adjudicated set exactly, and **case 28 is
its tripwire.** The lesson worth keeping: *the check that caught this was comparing the artifact
to the measurement, which is the one check the governance layer still does not have.*

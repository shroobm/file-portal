| origin clean | card | in sync, fetched, zero backlog |

**Cause:** S95 wrote its ledger row (hard clock) but never advanced the TIME-STATE line in
`MEMORY.md` (the soft clock's mirror). Its own §3 work plan step 8 committed to *"advance the
ledger and soft clock in lockstep"*; the ledger half landed, the mirror half did not. The cookie
half of the soft clock is consistent (tally 74 == hook 74).

**This incident is evidence for the repair it opens.** S95 ran the full muster, produced a 94 KB
whole-system document, and still skipped the mirror. That is not carelessness — it is the
structural cost of finding #2: the TIME-STATE block has grown into a ~77-line hand-maintained
narrative, and hand-maintained narrative is precisely what gets skipped at close. The two-clock
design worked exactly as intended: the disagreement was the detection.

**Reconciliation:** TIME-STATE is advanced to mirror the ledger (S95 / `b93218e` / row `42b1509`)
as part of this session's finding-#2 rewrite, and `open.sh` must exit 0 at close.

## §3 Work Plan

**Method: the shop — persistent counterparties, one writer.** Sub-agents are read-only by
capability (`Explore` type cannot Edit or Write), so a misaligned counterparty can be wrong but
never destructive. The orchestrator holds the pen and applies serially. The guardrails point at
the orchestrator, because in this shape the orchestrator is the risk.

1. **Record intent** (this file), before any mutation.
2. **Safety before edits** — snapshot the library to a dated sibling of the existing
   `memory-snapshot-2026-07-22/`, then `git init` the library and commit all 28 files as the
   baseline. Rab signed the git decision. This converts every later guardrail into `git diff`,
   permanently, rather than for this run only.
3. **Four counterparties, read-only, dispatched before drafting:**
   - **Surveyor** — re-measure everything `docs/39` claimed, plus the evidence the rewrites need
     (ledger S75–S95, docs map 00–39, exe lineage, held/vault state, symptom index, a SHA-256
     baseline manifest and the link graph). *A number is re-measured, never quoted.*
   - **Witness** — reads all 28 originals cold, **before any draft exists**, and pre-registers the
     load-bearing facts per file, plus the facts that appear in exactly one file. This is a
     Survival Audit run on the rewrite: the registered inventory is the reference window, fixed
     before the new text can anchor it.
   - **Adversary** — attacks the nine findings and the plan itself: which finding is false, where a
     "fix" destroys value, what the plan missed, whether `open.sh` would even catch a bad edit, and
     the strongest case for doing nothing.
   - **Namespace investigator** — discharges the S95 precondition above.
4. **Draft in quarantine.** Every proposed file is written to the scratchpad as
   `<name>.proposed.md`, never to the library. Each rewrite ships with a **removals ledger**: every
   fact dropped, with its justification (duplicated at X / superseded by evidence Y / folded to
   Historical). The author accounts for his own deletions in advance.
5. **Dispositions, not votes.** Every Witness omission and every Adversary objection receives a
   written disposition — *accepted-and-fixed*, or *refuted-with-evidence* (the evidence, not my
   say-so). An unanswered objection blocks the apply step. Silence from a dead agent is never a
   pass; it is re-spawned.
6. **Apply serially**, one writer, commit per repair in the library's new git.
7. **Acceptance:** `open.sh` exits 0 · index covers N/N with zero dangling · the SHA-256 manifest
   proves every file that should not have changed did not · TIME-STATE parses under whatever
   pattern `open.sh` actually uses (the Adversary is tasked with finding that parser).

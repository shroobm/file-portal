# docs/51 — The Numeration Census (NUM-1)

⟨claimed: Fable lane · Claude Fable 5 · post-S112 · 2026-08-31⟩

**The commission (Rab, 2026-08-31, via /echo Reading C, his word "Signed, Both"):**
*"Any numeration that increases, decreases, that is caught or defined in the ecosystem
of file portal, needs to be determined … each n+1 sequence."* This register is the
census half (NUM-1); the live counter on the glass (NUM-2) renders FROM these rows and
never invents one.

**Method:** eight read-only Opus lanes over the segments, each row citing the exact
increment site; docs/34 discipline throughout (numerator / denominator / conditions);
an honesty verdict per counter — SYM-066 (the [:25] display cap) is the canonical lie
shape hunted in every lane. Boundary vs A4 (`observability/schemas.json`, Codex):
A4 owns key NAMES and nesting; this register owns what the numbers MEAN and WHEN they
step. Census rows cite schema keys and never define them.

**Census totals:** 374 numerations registered across 8 lanes · **179 carry a FALSE honesty verdict** · 82 step with no name on any glass (discovery rows).

PART·01

The life of a book — today, unchanged

This is the manual's diagram, verbatim. Every state below exists and runs tonight. The proposal touches none of this topology — read it once, then find the one edge that changes: held → repaired, bottom-left.

Why that edge matters: the held/ pocket is not hypothetical — four patients sit in it right now (Damodaran · Valentine-repaired · Valentine-rerun · Cybernetics-stale), and all four carry the same wound: table-loop degeneration. S50 and S65 proved the other remedy arrows can't heal it — re-convert reproduces Marker's loop, and an analyst pass can't fix convert-phase damage. The Bench edge is the only one that works, and today it repairs with pixels.

PART·02

The proposal — inside the held → repaired edge

Today that edge is: drag a rectangle → 220-dpi crop → PNG embedded at the zone. The book keeps the truth, but as a picture — unsearchable, un-scorable, invisible to any future retrieval. The proposal expands the interior of the same gesture: the crop is read, the reading is governed, and only text that survives every gate reaches your accept button. Terracotta = new; everything else already exists.

The GPU objection, resolved by the research: the original sizing assumed a 7B vision model (~5.5–7 GB). Granite-Docling is ~27× smaller, purpose-built for exactly this task, and quantized builds run under Ollama with the pipeline's own keep_alive:0 pattern. The sledgehammer the concern was about no longer needs to exist. Serialization law unchanged: nothing wakes while .gpu-lock is held.

PART·05

Why text, not pixels — the downstream stakes

A pixel patch preserves truth a human can see; text preserves truth the system can use. Searchable in Obsidian. Re-scorable by the audit (the degeneration preview finally improves, because the loop is gone, not covered). And retrievable later: MixRAG's finding is that RAG over text-plus-table documents collapses unless table structure survives ingestion — its hierarchical row-and-column representations need real tables as input. The enrichment consumer this vault is heading toward will inherit exactly what the Bench writes today.
